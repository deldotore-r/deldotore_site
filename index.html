Ingestion Tasks Taking Hours, With No Errors


A pipeline kept reporting success while tasks that should take minutes ran for over four hours. Two years of tiny commits without snapshot expiration had grown the table's Iceberg metadata to more than 5,000 times the size of its data.

Tools: AWS CLI, kubectl, Python (fastavro, psycopg2)

Result: Root cause confirmed, investigation report and remediation plan; a follow-up scan found dozens of tables with the same pattern

In production
🌐

Spark Jobs Failing on New Nodes


Spark drivers failed seconds after the cluster scaled up. New nodes reported Ready in about 13 seconds, but pod networking took 2 to 3.5 minutes to converge. Confirmed with live measurements and EKS API server audit logs.

Stack: Amazon EKS, Calico, Cluster Autoscaler, CloudWatch Logs

Result: Four mitigation options documented; fix in progress

In production
🧹

Daily Platform Audit


A written morning protocol of 21 checks, backed by a dependency-free Python CLI that finds waste and stuck work across environments: crash-looping and OOM-killed pods, zombie Spark pods, orphaned EMR clusters, stuck DAG runs and orphaned Hive Metastore locks.

Tools: Python standard library, kubectl, AWS CLI

Highlight: Found idle EMR clusters with 18 instances and no auto-termination
